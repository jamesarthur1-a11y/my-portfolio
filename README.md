## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/jamesarthur1-a11y
```

### 2. Navigate to the Project Folder

```bash
cd my-portfolio
```

### 3. Run the Website

Open `index.html` in your web browser.

For a better development experience, you can use the Live Server extension in Visual Studio Code.

## 🌍 Deployment

This website is hosted using **GitHub Pages**.

To deploy your own version:

1. Create a GitHub repository.
2. Upload all project files and folders.
3. Open repository Settings.
4. Select Pages.
5. Choose `Deploy from a branch`.
6. Select the `main` branch and `/(root)` folder.
7. Click Save.
8. Wait for GitHub Pages to publish your website.
